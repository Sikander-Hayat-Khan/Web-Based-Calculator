# 🧮 Glassmorphism Web Calculator

A sleek, minimalistic web-based calculator featuring a modern "Glassmorphism" UI design and smooth interactive animations. Built entirely with vanilla HTML, CSS, and JavaScript.

## ✨ Features

* **Beautiful UI:** Features a high-end frosted glass effect (Glassmorphism) over a deep, elegant contrasting background.
* **Smooth Animations:** Satisfying tactile feedback with hover elevations and active scale/press effects.
* **Standard Math Operations:** Addition (`+`), subtraction (`-`), multiplication (`x`), and division (`/`).
* **Advanced Mathematical Functions:**
  * Square root (`√`)
  * Square (`x²`)
  * Reciprocal (`1/x`)
  * Sign toggle (`±`)
* **Complete Memory Functionality:**
  * **MS (Memory Store):** Saves the current value on the screen into memory.
  * **MR (Memory Recall):** Retrieves the saved value from memory to the screen.
  * **M+ (Memory Add):** Adds the currently displayed number to the value already stored in memory.
  * **MC (Memory Clear):** Erases the saved value from memory.

## 🛠️ Technologies Used

* **HTML5:** Semantic structuring wrapper.
* **CSS3:** Grid styling, Flexbox layouts, ambient drop-shadows, CSS backdrop-filters for the frosted glass effect, and transition animations.
* **JavaScript (ES6):** DOM manipulation, dynamic class assignment, event listener handling, and all underlying mathematical logic.
* **Typography:** [Inter](https://fonts.google.com/specimen/Inter) font provided by Google Fonts.

## 🚀 How to Run

1. Clone or download this repository to your local machine.
2. Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, installations, or dependencies are required!

## 📁 File Structure

* `index.html` — The main entry point containing the element hierarchy.
* `style.css` — Contains the Glassmorphism visual theme, grid layout, and interactive states.
* `script.js` — Contains the dynamic button generation and mathematical/memory logic.
